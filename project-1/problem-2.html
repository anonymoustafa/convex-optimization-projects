مسئله ۲: حذف نویز تغییر کل (Total Variation Denoising) یک‌بعدی

بازسازی سیگنال پله‌ای در حضور نویز گوسی و داده‌های پرت شدید از طریق فرم دوگان و الگوریتم L-BFGS-B

در این تمرین، مسئله‌ی حذف نویز تغییر کل (Total Variation Denoising) یک‌بعدی بررسی می‌شود:

$$\min_{x \in \mathbb{R}^{n}} \; \frac{1}{2}\Vert x - y \Vert_{2}^{2} + \lambda \Vert Dx \Vert_{1}$$

که در آن $D \in \mathbb{R}^{(n-1)\times n}$ ماتریس تفاضل مرتبه‌ی اول است و $(Dx)_i = x_{i+1} - x_i$ تغییرات محلی سیگنال را می‌سنجد.

برای حل دقیق و سریع این مسئله‌ی محدب، از فرم دوگان (Dual Formulation) آن استفاده می‌کنیم. با تعریف متغیر دوگان $w \in \mathbb{R}^{n-1}$ با قید جعبه‌ای $\Vert w \Vert_\infty \le \lambda$، مسئله به شکل زیر درمی‌آید که با الگوریتم L-BFGS-B به‌سادگی قابل حل است:

$$\min_{-\lambda \le w_i \le \lambda} \; \frac{1}{2}\Vert y - D^{T}w \Vert_{2}^{2}, \qquad x^{*} = y - D^{T}w^{*}$$

۱. کد پیاده‌سازی در پایتون (Python)

import matplotlib.pyplot as plt
import numpy as np
import scipy.optimize as opt

# ۱. تولید سیگنال پله‌ای اصلی با طول n = 200
np.random.seed(42)
n = 200
t = np.arange(n)

x_true = np.zeros(n)
x_true[30:80] = 3.0
x_true[80:130] = -2.0
x_true[130:170] = 4.0
x_true[170:] = 1.0

# ۲. افزودن نویز گوسی و ۱۲ نقطه‌ی پرت (Outliers) شدید
y = x_true + np.random.normal(0, 0.35, size=n)
outlier_indices = np.random.choice(n, size=12, replace=False)
y[outlier_indices] += np.random.choice([-5.0, 5.0], size=12)


# ۳. حل مسئله Total Variation Denoising از طریق فرم دوگان
def tv_denoise(y, lam):
  n = len(y)

  def DT(w):
    res = np.empty(n)
    res[0] = -w[0]
    res[1:-1] = w[:-1] - w[1:]
    res[-1] = w[-1]
    return res

  def obj_and_grad(w):
    x = y - DT(w)
    loss = 0.5 * np.sum(x**2)
    grad = -np.diff(x)
    return loss, grad

  bounds = [(-lam, lam)] * (n - 1)
  res = opt.minimize(
      obj_and_grad,
      np.zeros(n - 1),
      method='L-BFGS-B',
      jac=True,
      bounds=bounds,
      options={'ftol': 1e-12, 'gtol': 1e-10, 'maxiter': 5000},
  )
  return y - DT(res.x)


# ۴. حل برای سه مقدار لاندا و رسم نمودارها
lambdas = [0.1, 1.0, 10.0]
results = {lam: tv_denoise(y, lam) for lam in lambdas}

for lam, x_hat in results.items():
  mse = np.mean((x_hat - x_true) ** 2)
  tv = np.sum(np.abs(np.diff(x_hat)))
  print(f'lambda={lam}: MSE={mse:.4f}, TV={tv:.4f}')

plt.figure(figsize=(12, 9))
for idx, lam in enumerate(lambdas, 1):
  x_hat = results[lam]
  mse = np.mean((x_hat - x_true) ** 2)

  plt.subplot(3, 1, idx)
  plt.plot(t, x_true, 'k--', linewidth=1.8, label='Original Signal ($x_{true}$)')
  plt.plot(
      t,
      y,
      color='silver',
      marker='.',
      markersize=4,
      linestyle='-',
      linewidth=0.8,
      label='Noisy + Outliers ($y$)',
  )
  plt.plot(
      t,
      x_hat,
      color='#d62728',
      linewidth=2.2,
      label=f'TV Denoised ($\\lambda = {lam}$)',
  )
  plt.title(
      f'1D Total Variation Denoising ($\\lambda = {lam}$ | MSE = {mse:.4f})'
  )
  plt.ylabel('Amplitude')
  plt.ylim(-8.5, 10.5)
  plt.grid(True, alpha=0.3)
  plt.legend(loc='upper right')

plt.xlabel('Sample Index ($n$)')
plt.tight_layout()
plt.savefig('tv_denoising.png', dpi=150)
plt.show()

۲. نمودارهای خروجی و مقادیر عددی

نتایج اجرای کد بالا برای هر سه مقدار $\lambda$ در جدول و نمودارهای زیر قابل مشاهده است:

مقدار پارامتر ($\lambda$) خطای میانگین مربعات (MSE) تغییر کل سیگنال ($\Vert Dx \Vert_1$) وضعیت بازسازی
$\lambda = 0.1$ 1.4434 150.6571 بیش‌برازش به نویز و داده‌های پرت
$\lambda = 1.0$ 0.6729 71.8042 حذف نویز گوسی، اما باقی ماندن بخشی از داده‌های پرت
$\lambda = 10.0$ 0.3796 13.5673 حذف کامل نویز و نقاط پرت با حفظ تیز بودن لبه‌ها (همراه با اندکی افت دامنه)

۳. تحلیل تأثیر $\lambda$ بر هموارسازی و حفظ لبه‌ها

پارامتر $\lambda$ وزن جریمه‌ی تنکی تفاضل‌ها ($\Vert Dx \Vert_1$) را در برابر جمله‌ی وفاداری به داده ($\frac{1}{2}\Vert x - y \Vert_2^2$) کنترل می‌کند:

  1. مقدار کوچک ($\lambda = 0.1$) — غلبه‌ی وفاداری به داده:
    • جریمه‌ی اعمال‌شده بر پرش‌های متوالی بسیار ناچیز است. در نتیجه، سیگنال خروجی تقریباً روی سیگنال ورودی $y$ منطبق می‌شود.
    • نتیجه: نه نویز گوسیِ زمینه حذف می‌شود و نه داده‌های پرتِ تیز سرکوب می‌گردند (کم‌هموارسازی / Under-smoothing).
  2. مقدار متوسط ($\lambda = 1.0$) — حذف نویزهای کوچک و باقی ماندن اسپایک‌ها:
    • نوسانات کوچک ناشی از نویز گوسی ($\sigma = 0.35$) به‌خوبی صاف می‌شوند و بخش‌های ثابت سیگنال پله‌ای کاملاً تخت به نظر می‌رسند.
    • نتیجه: چون جریمه‌ی یک جهش تک‌نقطه‌ای با ارتفاع $h$ برابر با $2\lambda h$ است، برای داده‌های پرتِ شدید ($\vert h \vert \approx 5$) با $\lambda = 1$، الگوریتم تنها ارتفاع اسپایک‌ها را به اندازه‌ی $2\lambda = 2$ واحد کاهش می‌دهد اما نمی‌تواند آن‌ها را کاملاً حذف کند.
  3. مقدار بزرگ ($\lambda = 10.0$) — حذف داده‌های پرت، حفظ لبه‌ها و پدیده‌ی افت دامنه (Shrinkage):
    • حفظ لبه‌ها (Edge Preservation): برخلاف جریمه‌ی $\ell_2$ (فیلتر تیخونوف یا گوسی) که لبه‌های پله را پخ و تار می‌کند، نُرم $\ell_1$ پرش‌های بزرگ و طولانی (پله‌های اصلی سیگنال) را جریمه می‌کند ولی مکان و تیزی لبه را دقیقاً حفظ می‌کند.
    • حذف نقاط پرت: اسپایک‌های تک‌نقطه‌ای چون دو لبه‌ی متوالی مخالف دارند، هزینه‌ی تغییر کل بالایی ایجاد می‌کنند و در $\lambda = 10$ به‌طور کامل حذف می‌شوند.
    • افت دامنه (Amplitude Bias): با بزرگ شدن بیش‌ازحد $\lambda$، ارتفاع پله‌های واقعی نیز کمی به سمت میانگین کل سیگنال کشیده می‌شود (در بازه‌ی $n \in [130, 170]$ مقدار بازسازی‌شده کمی پایین‌تر از سطح واقعی $4.0$ قرار می‌گیرد). اگر $\lambda$ از این هم بزرگ‌تر شود، کل سیگنال به یک خط ثابت (میانگین $y$) تبدیل خواهد شد.
