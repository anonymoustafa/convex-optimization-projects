صورت تمرین عملی ۱ (پیاده‌سازی ۱)

حل مسئله کمترین مربعات (Least Squares) با استفاده از کتابخانه CVXPY و تحلیل حساسیت نسبت به نویز

در مسئله کمترین مربعات (Least Squares)، هدف ما یافتن برداری مانند $\hat{x}$ است که نرم دوم خطای باقیمانده یعنی $\Vert Ax - y \Vert_2$ (یا مربع آن $\Vert Ax - y \Vert_2^2$) را کمینه کند:

$$\min_{x \in \mathbb{R}^{20}} \Vert Ax - y \Vert_2$$

در ادامه، ابتدا کد کامل حل بخش اول برای $\sigma = 0.5$ (با seed = 42) و سپس کد مربوط به حلقه آزمایش روی مقادیر مختلف $\sigma$ همراه با رسم نمودار و تحلیل نتایج آورده شده است.

کد کامل پیاده‌سازی در پایتون

import cvxpy as cp
import matplotlib.pyplot as plt
import numpy as np

# ۱. تولید داده‌ها طبق صورت سوال (sigma = 0.5)
np.random.seed(42)
m, n = 100, 20
A = np.random.randn(m, n)
x_true = np.random.randn(n)
w_base = np.random.randn(m)  # بردار نویز استاندارد پایه برای مقایسه عادلانه

sigma_target = 0.5
w = sigma_target * w_base
y = A @ x_true + w

# ۲. تعریف و حل مسئله کمترین مربعات با cvxpy برای sigma = 0.5
x = cp.Variable(n)
objective = cp.Minimize(cp.sum_squares(A @ x - y))  # معادل کمینه کردن نرم دوم
problem = cp.Problem(objective)
problem.solve()

x_hat = x.value
error_norm = np.linalg.norm(x_hat - x_true, 2)

print(f"وضعیت حل مسئله (Status): {problem.status}")
print(f"نرم خطای تخمین برای sigma = 0.5: {error_norm:.4f}")

# ۳. تکرار آزمایش برای مقادیر مختلف sigma و رسم نمودار
sigmas = np.linspace(0.0, 2.0, 25)
errors = []

for s in sigmas:
  # تولید بردار مشاهدات با سطح نویز جدید
  y_s = A @ x_true + s * w_base

  # تعریف و حل مسئله بهینه‌سازی
  x_var = cp.Variable(n)
  prob = cp.Problem(cp.Minimize(cp.norm2(A @ x_var - y_s)))
  prob.solve()

  # محاسبه و ذخیره نرم خطا
  err = np.linalg.norm(x_var.value - x_true, 2)
  errors.append(err)

# ۴. رسم نمودار خطا بر حسب انحراف معیار نویز (sigma)
plt.figure(figsize=(8, 5))
plt.plot(
    sigmas,
    errors,
    marker='o',
    linestyle='-',
    color='b',
    label=r'$\|\hat{x} - x_{\mathrm{true}}\|_2$',
)
plt.title('نمودار تغییرات نرم خطای تخمین بر حسب انحراف معیار نویز ($\sigma$)')
plt.xlabel('انحراف معیار نویز ($\sigma$)')
plt.ylabel('نرم اقلیدسی خطا ($\|\hat{x} - x_{\mathrm{true}}\|_2$)')
plt.grid(True, linestyle='--', alpha=0.7)
plt.legend()
plt.tight_layout()
plt.show()

نمودار خروجی شبیه‌سازی

تحلیل نتایج و نمودار

  1. مقدار خطا در $\sigma = 0.5$: با اجرای بخش اول کد (با seed=42)، نرم اقلیدسی خطا ($\Vert \hat{x} - x_{\text{true}} \Vert_2$) عددی حدود 0.2286 به دست می‌آید. با توجه به اینکه ابعاد بردار $x$ برابر ۲۰ است و درایه‌های آن از توزیع نرمال استاندارد آمده‌اند (نرم $x_{\text{true}}$ حدود ۴.۵ است)، این خطا نشان‌دهنده دقت بسیار خوب تخمین‌گر کمترین مربعات در حضور نویز متوسط است.
  2. رفتار خطی نمودار خطا بر حسب $\sigma$: با مشاهده نمودار خروجی، متوجه می‌شویم که رابطه بین انحراف معیار نویز ($\sigma$) و نرم خطای تخمین ($\Vert \hat{x} - x_{\text{true}} \Vert_2$) کاملاً خطی است و از مبدأ مختصات می‌گذرد:
    • در $\sigma = 0$ (حالت بدون نویز): چون سیستم معادلات ما فرامعین است ($m = 100 > n = 20$) و ماتریس $A$ به صورت تصادفی با درایه‌های گاوسی ساخته شده (در نتیجه با احتمال ۱ دارای رتبه کامل ستونی است)، پاسخ به دست آمده دقیقاً برابر $x_{\text{true}}$ خواهد بود و خطا صفر می‌شود.
    • دلیل ریاضی خطی بودن: فرم بسته پاسخ مسئله کمترین مربعات به صورت $\hat{x} = (A^T A)^{-1} A^T y$ است. با جایگذاری $y = Ax_{\text{true}} + \sigma w_{\text{base}}$ داریم:
      $$\hat{x} = (A^T A)^{-1} A^T (Ax_{\text{true}} + \sigma w_{\text{base}}) = x_{\text{true}} + \sigma (A^T A)^{-1} A^T w_{\text{base}}$$
      بنابراین بردار خطا برابر است با:
      $$\Vert \hat{x} - x_{\text{true}} \Vert_2 = \sigma \cdot \Vert (A^T A)^{-1} A^T w_{\text{base}} \Vert_2$$
      از آنجا که ماتریس $A$ و بردار نویز پایه $w_{\text{base}}$ در طول حلقه ثابت نگه داشته شده‌اند، عبارت $\Vert (A^T A)^{-1} A^T w_{\text{base}} \Vert_2$ یک عدد ثابت است و خطای کل مستقیماً ضریبی خطی از $\sigma$ می‌شود. (نکته: اگر در هر تکرار حلقه نویز جدیدی با np.random.randn تولید کنید، نمودار همچنان یک روند صعودی خطی دارد اما حول خط میانگین کمی نوسان خواهد داشت).
